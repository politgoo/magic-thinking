# Эксперимент «Магия» для ВКР. Как открыть, доделать и запустить

Проект собран по образцу курсового проекта sevr3_calibr_sq3.psyexp (PsychoPy 2025.1.1, отправка данных в OSF через DataPipe). Файл эксперимента создан в формате версии 2025.2.1. При открытии в Builder 2025.1.1 появится предупреждение о более новой версии, его можно закрыть, структура совместима. Если что-то не откроется, поставьте PsychoPy 2025.2.x, это ближайшая стабильная ветка.

## Что в папке

magic_vkr.psyexp, файл эксперимента для Builder. tobacyk.xlsx, таблица с 26 пунктами опросника Тобасика в адаптации Григорьева (2015). build_magic.py, скрипт, которым файл собран; для работы он не нужен, но по нему видно, откуда что берётся.

## Устройство

Группа задаётся параметром group в ссылке (1, 2, 3 или 4), при пустом значении назначается случайно. Группы 1 и 2, опросник до кнопки; 3 и 4, после. Группы 1 и 3, лёгкая магия; 2 и 4, трудная (в тексте кнопки названо требование напечатать букву М не менее 30 раз).

Порядок рутин. welcome (согласие, разбор группы из диалога), debug_pick (отладочный экран выбора группы, показывается только если в диалоге ввести group = 0), setup (вычисление условий), tob_block_before (опросник, выполняется только если nBefore равно 1), choice_instr (текст инструкции по условию, переход пробелом), choice (только две кнопки; выбор мышью либо стрелкой влево = Магия, вправо = Пропустить; выбранная кнопка подсвечивается на 0,35 с; время от появления кнопок до выбора пишется в choice_rt), effort_loop (только для нажавших Магия: поле для печати, считаются число символов и число букв М), rating (важность события и зависимость исхода от себя, 0–100), tob_block_after (опросник для групп 3 и 4), suspicion (вопрос о цели исследования), row_entry (номер строки для студентов РАНХиГС, столбец row_number), thanks (разъяснение и отправка данных).

Столбцы данных. surname, age, row_number, group, order, cost, debug, tob_1 … tob_26, RPBS_* (семь субшкал, общий балл и среднее), choice, choice_rt, effort_len, effort_m, effort_time, importance.response, control.response, susp_box.text.

## Отладка

В диалоге запуска в поле «фамилия» введите 0, появится экран с четырьмя кнопками, и можно пройти любую группу. В данных такие прогоны помечены столбцом debug = 1, их нужно исключать при обработке. Для участников группа задаётся параметром group в ссылке (1, 2, 3, 4), в диалоге его нет; без параметра группа выбирается случайно (или через DataPipe, см. ниже).

В стартовом диалоге два поля, фамилия и возраст, они пишутся в столбцы surname и age и служат для начисления баллов и связи с гугл-формой. Остальные сведения о себе собираются в гугл-форме.

В опроснике ответ выбирается с клавиатуры: стрелки влево и вправо двигают отметку по шкале (первое нажатие ставит её на 4), клавиши 1–7 ставят ответ сразу, пробел подтверждает; пока ответ не выбран, пробел не действует. Мышь на шкале отключена. Время ответа на каждый пункт пишется в tob_rt_N. Инструкция к опроснику выровнена по левому краю, каждое значение шкалы на своей строке.

Курсор мыши включён в настройках эксперимента (Show mouse), поэтому он виден с первого экрана; кнопки Магия и Пропустить, поля ввода и кнопки Готово нажимаются мышью.

## Распределение по группам (сделать перед запуском)

Для равных ячеек используется распределение условий DataPipe (condition assignment). В настройках эксперимента на pipe.jspsych.org включить Condition assignment и задать 4 условия. Запрос к https://pipe.jspsych.org/api/condition с тем же experimentID, что и для отправки данных, возвращает номер условия по кругу (0, 1, 2, 3), к нему прибавляется 1 и получается группа. Этот запрос ещё нужно добавить в код рутины welcome (Begin JS Experiment), сейчас там случайный выбор при пустом group. При локальном запуске и при ошибке сети остаётся случайный выбор. Счётчик считает запуски, а не завершения, поэтому равенство завершённых ячеек проверять по participants.csv.

## Что доделать до запуска

1. пункты опросника уже вставлены из адаптации Григорьева (2015), таблица 7; шкала ответов и инструкция взяты оттуда же; пункт 23 обратный, баллы по семи субшкалам и общий балл считаются в конце эксперимента (столбцы RPBS_TRB, RPBS_Psi, RPBS_Witch, RPBS_Super, RPBS_Spirit, RPBS_ELF, RPBS_Precog, RPBS_total, RPBS_mean)
2. в рутине thanks, компонент code_datapipe, вкладка End JS Experiment, заменить ВСТАВИТЬ_ID_DATAPIPE на ID нового эксперимента в DataPipe (pipe.jspsych.org), привязанного к новому проекту OSF; ID курсового проекта использовать нельзя, данные смешаются; тот же ID используется для распределения по группам
3. проверить тексты экранов, они взяты из статьи Улыбиной и Шеенковой дословно, добавлена только фраза про букву М
4. прогнать локально (зелёная кнопка Run) во всех четырёх группах, вводя group в диалоге, и убедиться, что в папке data появляется csv с нужными столбцами

## Обработка данных

PsychoPy пишет по строке на каждый пункт опросника. Скрипт process_data.py сворачивает все csv из папки data в одну таблицу participants.csv, одна строка на участника, с пересчётом шкал и отметкой полноты. Запуск из папки проекта: python3 process_data.py data. Нужен pandas.

## Проверка времени

Время выбора считается от появления экрана с кнопками (рутина choice, без текста инструкции) до клика или нажатия стрелки. Чтение инструкции на него не влияет, оно идёт на предыдущем экране. Перед пилотом пройти в трёх браузерах и убедиться, что choice_rt в секундах с долями и что при нажатии Пропустить значение тоже пишется.

## Что стоит согласовать с научным руководителем

Формулировка про букву М и порог 30. Оставлять ли обязательную вторую часть для лёгкой магии (сейчас поле с буквами показывается всем, кто нажал Магия, в обеих версиях, чтобы мера усилия была сопоставима). Нужен ли отдельный шаг с номером строки для баллов, как в курсовом проекте.
